Responsabilidades por módulo

🎛
app.py — Orquestador Central: Inicializa la cámara, el logo de footer y los módulos de visión y UI. Mantiene el bucle while principal a 30 FPS, omite MediaPipe en los estados COUNTDOWN y CAPTURED para ahorrar CPU, gestiona el peace_dwell con arco de progreso visual, y compone la foto final (frame + stickers + logo, sin controles de UI). Limpia los stickers colocados tras cada captura.
🧠
vision_engine.py — Motor de Percepción: Encapsula MediaPipe Hands. Procesa el frame a escala 50% antes de enviarlo a MediaPipe (mitad de píxeles, sin pérdida de calidad). Expone: process_frame(frame) → HandState, draw_landmarks(frame) para visualizar el esqueleto de la mano, _classify(lm) con match-case y alpha_blend(canvas, sticker, x, y) estático. Los stickers se cargan con tinte blanco forzado (img[..., :3] = 255).
🖼
ui_manager.py — Capa de Presentación: Carga stickers PNG y SVG (vía cairosvg), aplica tinte blanco y pre-genera thumbnails para evitar resize por frame. setup_layout(w, h) calcula las ROIs de botones cada frame antes de update_collisions(). Renderiza la franja superior con thumbnails pre-calculados. Soporta arrastre de stickers con guard contra la franja UI. clear_stickers() limpia los stickers tras cada foto.

src/vision_engine.py Python — Alpha Blending + MediaPipe 
from __future__ import annotations
import cv2
import numpy as np
import mediapipe as mp
from dataclasses import dataclass
from enum import Enum, auto
from config import *

# ─── Gestos reconocidos ────────────────────────────────────────────
class Gesture(Enum):
    NONE         = auto()
    PEACE        = auto()  # ✌ disparador de foto
    POINTING     = auto()  # ☝ navegación / drag


@dataclass
class HandState:
    landmarks     : list             # 21 puntos normalizados
    gesture       : Gesture
    index_tip_px  : tuple[int, int]  # coordenadas píxel del índice


class VisionEngine:
    """Encapsula MediaPipe Hands y las operaciones de imagen."""

    def __init__(self) -> None:
        self._mp_hands = mp.solutions.hands
        self._hands = self._mp_hands.Hands(
            max_num_hands        = MP_MAX_HANDS,
            min_detection_confidence = MP_MIN_DETECTION_CONF,
            min_tracking_confidence  = MP_MIN_TRACKING_CONF,
        )
        self._draw = mp.solutions.drawing_utils

    # ── Detección ──────────────────────────────────────────────────
    def process_frame(self, bgr_frame: np.ndarray) -> HandState | None:
        h, w = bgr_frame.shape[:2]
        # Escalar al 50% antes de MediaPipe — mitad de píxeles procesados
        small   = cv2.resize(bgr_frame, (int(w * MP_DETECT_SCALE), int(h * MP_DETECT_SCALE)))
        rgb     = cv2.cvtColor(small, cv2.COLOR_BGR2RGB)
        results = self._hands.process(rgb)
        self._last_results = results

        if not results.multi_hand_landmarks:
            return None

        lm  = results.multi_hand_landmarks[0].landmark
        tip = lm[8]  # INDEX_FINGER_TIP
        # Landmarks normalizados [0,1] — proyectar sobre dimensiones full-res
        index_px = (int(tip.x * w), int(tip.y * h))

        return HandState(
            landmarks    = lm,
            gesture      = self._classify(lm),
            index_tip_px = index_px,
        )

    def draw_landmarks(self, frame: np.ndarray) -> None:
        """Dibuja el esqueleto de la mano sobre frame para todas las manos detectadas."""
        if self._last_results is None or not self._last_results.multi_hand_landmarks:
            return
        dot  = self._draw_utils.DrawingSpec(color=(0,255,120), thickness=1, circle_radius=3)
        line = self._draw_utils.DrawingSpec(color=(255,255,255), thickness=1)
        for hand_lm in self._last_results.multi_hand_landmarks:
            self._draw_utils.draw_landmarks(
                frame, hand_lm, self._mp_hands.HAND_CONNECTIONS, dot, line,
            )

    # ── Clasificación de gestos ────────────────────────────────────
    def _classify(self, lm) -> Gesture:
        # Tip IDs: thumb=4, index=8, middle=12, ring=16, pinky=20
        # MCP IDs: index=5, middle=9, ring=13, pinky=17
        def extended(tip, mcp): return lm[tip].y < lm[mcp].y

        idx    = extended(8,  5)
        mid    = extended(12, 9)
        ring   = extended(16, 13)
        pinky  = extended(20, 17)

        match (idx, mid, ring, pinky):
            case (True, True, False, False):  return Gesture.PEACE
            case (True, False, False, False): return Gesture.POINTING
            case _:                              return Gesture.NONE

    # ── Alpha Blending (núcleo del renderizado) ────────────────────
    @staticmethod
    def alpha_blend(
        canvas  : np.ndarray,       # frame BGR (H×W×3)
        sticker : np.ndarray,       # PNG BGRA  (h×w×4)
        x       : int,               # esquina superior-izquierda
        y       : int,
    ) -> np.ndarray:
        """
        Mezcla `sticker` sobre `canvas` en la posición (x, y).
        Opera en float32 para precisión y regresa uint8.
        Recorta silenciosamente si el sticker desborda el canvas.
        """
        sh, sw = sticker.shape[:2]
        ch, cw = canvas.shape[:2]

        # ── Calcular ROI válida ─────────────────────────────────────
        x1, y1 = max(x, 0), max(y, 0)
        x2, y2 = min(x + sw, cw), min(y + sh, ch)

        if x2 <= x1 or y2 <= y1:
            return canvas  # sticker fuera de pantalla

        # Región del sticker que cae dentro del canvas
        sx1 = x1 - x; sy1 = y1 - y
        sx2 = sx1 + (x2 - x1); sy2 = sy1 + (y2 - y1)

        # ── Extraer canales ─────────────────────────────────────────
        roi     = canvas[y1:y2, x1:x2].astype(np.float32)
        s_crop  = sticker[sy1:sy2, sx1:sx2]
        alpha   = s_crop[..., 3:] / 255.0  # shape (h,w,1)
        s_bgr   = s_crop[..., :3].astype(np.float32)

        # ── Mezcla: out = alpha·sticker + (1−alpha)·background ──────
        blended = alpha * s_bgr + (1.0 - alpha) * roi

        canvas[y1:y2, x1:x2] = blended.astype(np.uint8)
        return canvas
src/ui_manager.py Python — Colisión con Delay de Frames 
from __future__ import annotations
import cv2
import numpy as np
from dataclasses import dataclass, field
from pathlib import Path
from config import *


@dataclass
class StickerInstance:
    """Un sticker colocado en el canvas con posición libre."""
    img  : np.ndarray  # BGRA, tamaño STICKER_CANVAS_SIZE
    x    : int
    y    : int
    name : str = ""
    dragging: bool = False


@dataclass
class ButtonROI:
    """Zona de interés de un botón con contador de dwell."""
    label   : str
    x1, y1  : int
    x2, y2  : int
    dwell   : int = 0   # frames dentro del ROI
    cooldown: int = 0   # frames de espera post-disparo

    def contains(self, pt: tuple[int,int]) -> bool:
        return self.x1 <= pt[0] <= self.x2 and \
               self.y1 <= pt[1] <= self.y2

    def update(self, inside: bool) -> bool:
        """
        Avanza el contador de dwell.
        Retorna True cuando se alcanza COLLISION_DWELL_FRAMES
        por primera vez (disparo único con cooldown).
        """
        if self.cooldown > 0:
            self.cooldown -= 1
            self.dwell = 0
            return False

        if inside:
            self.dwell += 1
            if self.dwell >= COLLISION_DWELL_FRAMES:
                self.dwell    = 0
                self.cooldown = 20  # pausa anti-rebote
                return True
        else:
            self.dwell = 0

        return False

    def progress(self) -> float:
        """0.0 → 1.0 — para barra de progreso visual."""
        return min(self.dwell / COLLISION_DWELL_FRAMES, 1.0)


class UIManager:
    def __init__(self, sticker_paths: list[Path]) -> None:
        self._library   = [self._load(p) for p in sticker_paths]
        self._names     = [p.stem for p in sticker_paths]
        self._page      = 0
        self._placed    : list[StickerInstance] = []

        # Botones — posicionados en render()
        self._btn_prev = ButtonROI("◀", 0,0,0,0)
        self._btn_next = ButtonROI("▶", 0,0,0,0)

    def _load(self, path: Path) -> np.ndarray:
        if path.suffix.lower() == ".svg":
            import cairosvg
            png_bytes = cairosvg.svg2png(url=str(path.resolve()),
                            output_width=STICKER_CANVAS_SIZE, output_height=STICKER_CANVAS_SIZE)
            arr = np.frombuffer(png_bytes, dtype=np.uint8)
            img = cv2.imdecode(arr, cv2.IMREAD_UNCHANGED)
        else:
            img = cv2.imread(str(path), cv2.IMREAD_UNCHANGED)
        if img is None:
            raise FileNotFoundError(path)
        if img.ndim == 2:
            img = cv2.cvtColor(img, cv2.COLOR_GRAY2BGRA)
        elif img.shape[2] == 3:
            img = cv2.cvtColor(img, cv2.COLOR_BGR2BGRA)
        img[..., :3] = 255  # tinte blanco: preserva alpha, fuerza BGR a blanco
        return cv2.resize(img, (STICKER_CANVAS_SIZE,)*2)

    def setup_layout(self, w: int, h: int) -> None:
        """Calcula posiciones ROI para frame de tamaño (w, h).
        Llamar ANTES de update_collisions() cada frame."""
        bx  = 10
        by  = (STRIP_HEIGHT - BUTTON_H) // 2
        bx2 = w - BUTTON_W - 10
        self._btn_prev.__dict__.update(x1=bx,  y1=by, x2=bx+BUTTON_W,  y2=by+BUTTON_H)
        self._btn_next.__dict__.update(x1=bx2, y1=by, x2=bx2+BUTTON_W, y2=by+BUTTON_H)
        # thumbnails centrados en la franja
        thumb_x1 = bx + BUTTON_W + 10
        spacing  = (bx2 - 10 - thumb_x1) // max(STICKERS_PER_PAGE, 1)
        ts       = STICKER_THUMB_SIZE
        for i, btn in enumerate(self._thumb_buttons):
            tx = thumb_x1 + i * spacing + (spacing - ts) // 2
            ty = (STRIP_HEIGHT - ts) // 2
            btn.__dict__.update(x1=tx, y1=ty, x2=tx+ts, y2=ty+ts)

    def current_page_stickers(self):
        start = self._page * STICKERS_PER_PAGE
        return self._library[start:start + STICKERS_PER_PAGE]

    def update_collisions(self, index_tip: tuple | None) -> None:
        """Actualiza dwell frames de cada botón según posición del índice."""
        pt = index_tip or (-1, -1)
        if self._btn_prev.update(self._btn_prev.contains(pt)):
            self._page = (self._page - 1) % self._total_pages()
        if self._btn_next.update(self._btn_next.contains(pt)):
            self._page = (self._page + 1) % self._total_pages()

    def _total_pages(self) -> int:
        return max(1, -(-len(self._library) // STICKERS_PER_PAGE))

    def render_ui(self, frame: np.ndarray) -> np.ndarray:
        """Dibuja franja superior + botones. Posiciones vienen de setup_layout()."""
        h, w = frame.shape[:2]

        # Mezclar solo las filas de la franja — evita copiar el frame completo
        strip_copy = frame[:STRIP_HEIGHT].copy()
        cv2.addWeighted(self._strip_bg, 0.75, strip_copy, 0.25, 0, frame[:STRIP_HEIGHT])

        # Botones con barra de progreso
        for btn in (self._btn_prev, self._btn_next):
            p = btn.progress()
            cv2.rectangle(frame,(btn.x1,btn.y1),(btn.x2,btn.y2),(40,40,60),-1)
            if p > 0:
                fill_w = int((btn.x2 - btn.x1) * p)
                cv2.rectangle(frame,(btn.x1,btn.y1),
                              (btn.x1+fill_w, btn.y1+4),(0,220,180),-1)
            cv2.putText(frame, btn.label,
                        (btn.x1+12, btn.y1+BUTTON_H//2+8),
                        cv2.FONT_HERSHEY_SIMPLEX, 1.2, (220,220,240), 2)

        return frame

    def clear_stickers(self) -> None:
        """Elimina todos los stickers colocados. Llamado tras cada captura."""
        self._placed.clear()
        self._drag_idx = None

    @property
    def placed_stickers(self): return self._placed
src/app.py Python — Main Loop + Countdown + Captura Limpia 
from __future__ import annotations
import cv2
import numpy as np
import time
from datetime import datetime
from enum import Enum, auto
from config import *
from vision_engine import VisionEngine, Gesture
from ui_manager import UIManager


class AppState(Enum):
    IDLE        = auto()   # interacción normal
    COUNTDOWN   = auto()   # cuenta regresiva activa
    CAPTURED    = auto()   # flash post-captura


def render_countdown(frame: np.ndarray, n: int) -> None:
    """Dibuja el número de cuenta regresiva centrado, con halo."""
    h, w = frame.shape[:2]
    text = str(n)
    font = cv2.FONT_HERSHEY_SIMPLEX
    scale = 8.0; thick = 16
    (tw, th), _ = cv2.getTextSize(text, font, scale, thick)
    org = ((w - tw) // 2, (h + th) // 2)
    # halo negro
    cv2.putText(frame, text, org, font, scale, (0,0,0), thick+8)
    # texto cyan
    cv2.putText(frame, text, org, font, scale, (0,230,255), thick)


def _load_logo(path: Path, height: int) -> np.ndarray | None:
    if not path.exists(): return None
    img = cv2.imread(str(path), cv2.IMREAD_UNCHANGED)
    if img is None: return None
    if img.shape[2] == 3: img = cv2.cvtColor(img, cv2.COLOR_BGR2BGRA)
    h, w = img.shape[:2]
    new_w = max(1, int(w * height / h))
    return cv2.resize(img, (new_w, height))


def save_clean_capture(
    raw_frame: np.ndarray,
    ui       : UIManager,
    engine   : VisionEngine,
    logo     : np.ndarray | None = None,
) -> Path:
    """frame puro + stickers + logo de footer, SIN controles de UI."""
    clean = raw_frame.copy()
    for s in ui.placed_stickers:
        clean = VisionEngine.alpha_blend(clean, s.img, s.x, s.y)
    if logo is not None:
        fh, fw = clean.shape[:2]
        lh, lw = logo.shape[:2]
        clean = VisionEngine.alpha_blend(clean, logo,
                   fw - lw - FOOTER_MARGIN, fh - lh - FOOTER_MARGIN)
    ts   = datetime.now().strftime("%Y%m%d_%H%M%S")
    path = CAPTURES_DIR / f"photo_{ts}.png"
    cv2.imwrite(str(path), clean)
    return path


def main() -> None:
    cap = cv2.VideoCapture(0)
    cap.set(cv2.CAP_PROP_FRAME_WIDTH,  FRAME_WIDTH)
    cap.set(cv2.CAP_PROP_FRAME_HEIGHT, FRAME_HEIGHT)
    cap.set(cv2.CAP_PROP_FPS,          TARGET_FPS)

    engine = VisionEngine()
    ui     = UIManager(STICKER_FILES)
    logo   = _load_logo(FOOTER_LOGO, FOOTER_LOGO_HEIGHT)

    state          : AppState        = AppState.IDLE
    countdown_start: float           = 0.0
    flash_alpha    : float           = 0.0
    last_raw       : np.ndarray | None = None
    peace_dwell    : int             = 0

    cv2.namedWindow("Open Source Photo Booth", cv2.WINDOW_NORMAL)

    while cap.isOpened():
        ok, frame = cap.read()
        if not ok: break

        frame    = cv2.flip(frame, 1)
        last_raw = frame.copy()
        # Saltar MediaPipe en estados no interactivos
        hand = engine.process_frame(frame) if state == AppState.IDLE else None

        for s in ui.placed_stickers:
            frame = VisionEngine.alpha_blend(frame, s.img, s.x, s.y)

        match state:
            case AppState.IDLE:
                engine.draw_landmarks(frame)
                fh, fw = frame.shape[:2]
                ui.setup_layout(fw, fh)
                ui.update_collisions(
                    hand.index_tip_px if hand else None,
                    is_pointing=hand is not None and hand.gesture == Gesture.POINTING,
                )
                frame = ui.render_ui(frame)

                # Cursor del dedo
                if hand:
                    ix, iy = hand.index_tip_px
                    cv2.circle(frame, (ix, iy), 10, (0,0,0),    -1)
                    cv2.circle(frame, (ix, iy),  8, (0,230,255), -1)

                # PEACE dwell con arco de progreso
                if hand and hand.gesture == Gesture.PEACE:
                    peace_dwell += 1
                    ix, iy   = hand.index_tip_px
                    progress = peace_dwell / PEACE_DWELL_FRAMES
                    sweep    = int(360 * progress)
                    cv2.ellipse(frame, (ix, iy), (24,24), -90, 0, 360,  (50,50,50),   2)
                    cv2.ellipse(frame, (ix, iy), (24,24), -90, 0, sweep, (0,230,255), 3)
                    if peace_dwell >= PEACE_DWELL_FRAMES:
                        state           = AppState.COUNTDOWN
                        countdown_start = time.time()
                        peace_dwell     = 0
                else:
                    peace_dwell = 0

            case AppState.COUNTDOWN:
                elapsed = time.time() - countdown_start
                n       = COUNTDOWN_SECONDS - int(elapsed)
                if n > 0:
                    render_countdown(frame, n)
                else:
                    path = save_clean_capture(last_raw, ui, engine, logo)
                    print(f"Saved: {path}")
                    ui.clear_stickers()   # limpiar para la siguiente sesión
                    state       = AppState.CAPTURED
                    flash_alpha = 1.0

            case AppState.CAPTURED:
                if flash_alpha > 0:
                    white = np.ones_like(frame, dtype=np.uint8) * 255
                    cv2.addWeighted(white, flash_alpha,
                                   frame, 1 - flash_alpha, 0, frame)
                    flash_alpha -= 0.08
                else:
                    state = AppState.IDLE

        # Logo de footer siempre visible en vista en vivo
        if logo is not None:
            fh, fw = frame.shape[:2]
            lh, lw = logo.shape[:2]
            VisionEngine.alpha_blend(frame, logo,
                fw - lw - FOOTER_MARGIN, fh - lh - FOOTER_MARGIN)

        cv2.imshow("Open Source Photo Booth", frame)
        if cv2.waitKey(1) & 0xFF == ord("q"):
            break

    cap.release()
    cv2.destroyAllWindows()

06 — Lógica de Colisión

ROI con Delay de Frames

VISUALIZACIÓN DEL DWELL
ROI Botón ▶
Índice dentro del área:
6 / 12 frames → 50%
Al frame 12 → 🔥 DISPARO
Cooldown: 20 frames más

¿Por qué delay de frames?

Los gestos de mano tienen jitter natural: el dedo entra y sale del área del botón en milisegundos incluso cuando el usuario intenta permanecer inmóvil. Un clic por contacto dispararía acciones falsas constantemente.

El contador dwell exige que el landmark permanezca dentro del ROI durante 12 frames consecutivos (~0.4 s a 30 FPS). Si el dedo sale aunque sea un frame, el contador vuelve a 0. Esto elimina clics accidentales sin sacrificar responsividad.

El cooldown de 20 frames post-disparo evita que una acción se repita inmediatamente si la mano sigue sobre el botón.

09 — Notas Técnicas

Consideraciones Importantes

⚠️
BGR vs BGRA: OpenCV lee imágenes en BGR por defecto. Los PNGs con transparencia deben cargarse con cv2.IMREAD_UNCHANGED para preservar el canal alpha (canal 3). El alpha blending opera en float32 para evitar overflow y se convierte de vuelta a uint8 solo al escribir en el canvas.
🚀
Optimizaciones de FPS implementadas:
  • Escala 50% antes de MediaPipe — MP_DETECT_SCALE=0.5 reduce a la mitad los píxeles procesados sin impacto perceptible en la detección de landmarks.
  • Saltar inferencia en COUNTDOWN/CAPTURED — MediaPipe solo corre en estado IDLE; los otros estados no necesitan tracking de mano.
  • Thumbnails pre-calculados — UIManager genera versiones thumbnail al init y las reutiliza cada frame, eliminando el cv2.resize por frame.
  • Blend parcial de franja — render_ui() opera solo sobre las primeras STRIP_HEIGHT filas del frame en vez de copiar el frame completo.
🔧
Comandos uv esenciales:
uv sync — instala dependencias según pyproject.toml
uv run python src/app.py — ejecuta en el entorno gestionado
uv run pytest tests/ — ejecuta tests
uv add mediapipe — añade nueva dependencia
🎨
Stickers de calidad: Los PNGs ideales tienen fondo transparente, bordes suavizados (anti-aliased) y resolución mínima de 256×256 px. Se recomienda descargar los logos oficiales desde Wikipedia Commons o los repos oficiales de cada proyecto, que suelen ser SVG convertibles a PNG con Inkscape.
